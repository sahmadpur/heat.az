🎨 DESIGN SYSTEM & UI/UX SPEKSİFİKASİYASI (YENİLƏNMİŞ)
1. Rəng Palitrası (Color Palette)
Ağır sənaye mühəndisliyi, istilik/odluq sistemləri, buxar və avtomatlaşdırmanı təmsil edən balanslı rəng sxemi:
•	Dominant/Əsas Rəng (60% - Fonlar və Sənaye Blokları):
o	Deep Industrial Slate / Dark Graphite (#1A1D20 və ya #121517) — Müasir, ciddi, texniki və güclü mühəndislik fonu.
•	İkinci Dərəcəli Rəng (30% - Kartlar, Neytral Hissələr, İşıqlı Sahələr):
o	Cool Steel / Light Gray (#262C33 / #F5F7FA) — Aydın oxunma və təmiz texniki struktur üçündür.
•	Vurğu / Accent Rəngləri (10% - İstilik/Od və Təhlükəsizlik/Avtomatika):
o	Thermal Orange / Amber (#FF5722 və ya #E65100) — Odluq (burner), istilik, qazanxana və əsas çağırış (CTA) düymələri üçün Vurğu Rəngi.
o	Cyan / Tech Electric Blue (#00ACC1 və ya #0288D1) — Sensorlar, avtomatika, $\text{CO}_2$ idarəetməsi və baca qazı analizatoru blokları üçün texnoloji vurğu rəngi.
2. Tipoqrafiya və Şrift Konsepsiyası
•	Şrift Üslubu: Həndəsi, kəskin oxunan və müasir Sans-Serif fontlar.
o	Tövsiyə olunan fontlar: Inter, Montserrat və ya Roboto.
•	Başlıqlar (H1, H2, H3): Bold / Semi-Bold, yığcam hərf aralığı (letter-spacing: -0.5px).
•	Mətnlər (Body Text): Regular, 16px - 18px (sətir arası məsafə line-height: 1.6).
3. Bölmələr Üzrə Dizayn və Forma Təlimatları
🖼️ 1. Hero Section (Giriş Banneri)
•	Forma: İki sütunlu asimmetrik plan (60/40).
o	Sol tərəf: Tünd qrafit fonda aydın başlıq, narıncı və texniki-göy vurgulu düymələr.
o	Sağ tərəf: Fonu tündləşdirilmiş real sənaye qazanxanası/odluq avadanlığı fotosu və ya izometrik 3D mühəndislik modeli.
•	Stil: Arxa fonda həfif istilik/buxar mikrodinamikası (subtle particle effect).
📊 2. Rəqəmlərlə Biz (Statistika Bloku)
•	Forma: 4 sütunlu tor (Grid) və ya bütöv üfqi panel.
•	Rəng: Tünd fondan fərqlənən yarı-şəffaf kartlar (Glassmorphism: rgba(255,255,255,0.04)).
•	Vizual: Rəqəmlər böyük şriftlə Thermal Orange rəngində, yanında xüsusi sənaye ikonları (zaman, faiz, zəmanət v.s.).
🛠️ 3. Əsas Xidmətlərimiz (6 Əsas Xidmət)
•	Forma: 3x2 formatında şəbəkə kartları (Grid).
•	Kartların Dizaynı:
o	Kənarları həfif yuvarlaqlaşdırılmış (border-radius: 12px).
o	Hover effekti: Maus gəldikdə kart həfif yuxarı qalxır (translateY(-5px)), kənar xətti narıncı/sian işıqlanma verir.
o	Hər xidmətin daxilində minimal vektor sənaye ikonu (Line-art style).
🔬 4. Xüsusi Xidmət: Baca Qazı Analizi (Xüsusi Blok)
•	Forma: Tam enli (Full-width) rəqəmsal laboratoriya və indikator stili.
•	Rəng: Tünd göy / Sian vurğulu xüsusi arxa fon (Tech Navy / Cyan).
•	Vizual:
o	Sol tərəfdə rəqəmsal analizator cihazı panelini xatırladan göstərici kartları ($\text{CO}, \text{CO}_2, \text{NO}_x, \text{O}_2$).
o	Sağ tərəfdə tənzimləmə və səmərəlilik üstünlüklərinin siyahısı (Tab və ya Akordeon).
⚖️ 5. Xidmət Modelləri (Müqayisə Cədvəli)
•	Forma: 2 Sütunlu Yan-Yana Müqayisə Kartları.
•	Dizayn:
o	Birdəfəlik Təmir kartı: Standart neytral kənarlıqlar və boz tonlar.
o	Dövri Texniki Xidmət kartı: Narıncı çərçivə, üst hissədə "Maksimum Qənaət və Təhlükəsizlik" etiketi (Badge) ilə vurğulanmış xüsusi kart fonu.
🏢 6. İxtisaslaşdığımız Sahələr (Obyektlər)
•	Forma: 4 Sütunlu Kartlar (Asfalt Zavodları, Aqrokomplekslər, Fabriklər, Yaşayış Binaları).
•	Dizayn: Hər obyektin arxasında real sənaye sahəsinin fotosu üzərində tünd gradient örtüyü (Dark Overlay) və aydın oxunan text.
🤝 7. Əməkdaşlıq və Partnyorlar (Loqo Bölməsi)
•	Forma: Üfüqi sonsuz karusel (Infinite Slider) və ya təmiz 5-6 sütunlu grid.
•	Dizayn: Loqolar standart halda monoxrom (ağ-qara/kulisləşdirilmiş), maus ilə üzərinə gəldikdə orijinal rənginə keçən formada.
📜 8. Sertifikatlar və Lisenziyalar
•	Forma: 3 və ya 4 sütunlu İşıq Qutusu (Lightbox / Modal).
•	Dizayn: Sertifikatların skan versiyaları kənarları çərçivəli mini-kartlar kimi görünür. Kliklədikdə ekranda böyük modal pəncərədə açılır. Altında rəsmi qurum etiketi (FHN, ISO və s.) yerləşdirilir.
❓ 9. Tez-Tez Verilən Suallar (FAQ)
•	Forma: Səliqəli şaquli Akordeon siyahısı.
•	Dizayn: Kliklədikdə yumşaq keçidlə (smooth transition) açılan və narıncı ox/plus ikonu olan bloklar.
📞 10. Əlaqə və Təcili Çağırış (CTA & Form)
•	Forma: İki tərəfli bölünmüş modul (Əlaqə məlumatları + Sifariş formu).
•	Dizayn: Form sahələri klikləndikdə narıncı xətlərlə işıqlanır. "Sorğunu Göndər" düyməsi iri, parlaq narıncı rəngdə və aydın görünən stildədir.
